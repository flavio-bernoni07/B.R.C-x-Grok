# Phone claim — filmed demo (~60–90s)

**Setup (off camera):** `pnpm phone:demo` running, Voice Agent tool URL set, number Live. Run `pnpm phone:clear` so no rehearsal Phone rows remain. Browser on **Disputes** at `http://127.0.0.1:3000/disputes`. Phone on speaker.

---

### VO (over Disputes, before the call)

> Here’s a quick demo of how we’ve facilitated the process of reporting a claim for your clients — and keeping track of it internally.
> A retailer calls Riso Scotti. Grok takes the claim live. It lands here on Disputes — same desk as email.

### On camera

1. Show **Disputes** (no new Phone row yet).
2. Dial the xAI number (speaker on).
3. After the greeting, say clearly:

> Hi — this is Esselunga. Order ORD-3001. Shortage: we received only eleven hundred of twelve hundred Carnaroli.

4. Wait until Grok says a **DSP-…** reference.
5. Refresh / focus **Disputes** — open the new row (**Phone** badge).
6. One line VO:

> Same Mini ERP. Code checked the order; a person only steps in when it’s ambiguous.

### Optional second beat (ambiguous → Sign-off)

Call again:

> Carrefour, order ORD-3003. Sixty Arborio packs crushed on arrival.

Show **Disputes** → open claim → if it needs a person, cut to **Sign-off**.

---

**Don’t:** invent a DSP id; promise a credit on the call; leave the tunnel terminal stopped mid-take.
