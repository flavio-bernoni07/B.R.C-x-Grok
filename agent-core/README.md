# agent-core

General-purpose local agent built with [eve](https://github.com/vercel/eve) and Grok (xAI), with a web chat UI. It runs fully on this machine, with no Vercel account, no Docker and no database server.

- **Model:** `grok-4.7` via `@ai-sdk/xai`, called directly (`agent/agent.ts`). Change it with `GROK_MODEL`.
- **Sandbox:** just-bash, a pure-JavaScript shell with a virtual filesystem (`agent/sandbox.ts`).
- **Sessions:** eve's local Workflow world, stored as files in `.eve/.workflow-data` (gitignored).
- **Auth:** `localDev()` only, so it is open on localhost (`agent/channels/eve.ts`).
- **Web UI:** eve's Web Chat (Next.js) in `apps/web/`, generated by `eve add channel/web`. Next.js also hosts the agent, so one command runs both.

## Paddy price forecaster

The app opens on one thread. The first message tells this week's price story with one chart, and your questions and Rice Agent's answers continue below it.

| Piece | Where |
|---|---|
| Data download, Prophet baseline, backtest | `../planning/rice_forecast/` (Python, uv), writes `../data/raw/` |
| Shared data layer for tools and UI | `agent/lib/rice.ts` |
| Agent tools | `agent/tools/rice_*.ts` |
| Outlook procedure | `agent/skills/price-outlook/SKILL.md` |
| UI cards (intro, forecast, market, news) | `apps/web/components/rice/` |

The intro and the chat cards call the same functions as the agent's tools (`/api/rice/*` → `agent/lib/rice.ts`), so the screen and Grok always see the same numbers. News comes from Grok's own web and X search (xAI Agent Tools).

## Setup

Requires Node 24 (`nvm use` reads `.nvmrc`), pnpm and [uv](https://docs.astral.sh/uv/).

```bash
cd agent-core
nvm use
pnpm install
pnpm setup:py                 # Python env for the forecaster
cp .env.example .env.local    # then set XAI_API_KEY=xai-...
pnpm data:fetch               # optional: refresh data/raw/ (it ships in the repo)
```

## Run

| Command | What it starts |
|---|---|
| `pnpm dev:web` | Web chat on http://localhost:3000, with the agent inside it |
| `pnpm dev` | The agent alone, in eve's terminal UI |
| `pnpm dev --no-ui` | The agent alone, HTTP only, on http://127.0.0.1:2000 |

## Adding eve integrations (`eve add ...`)

`.npmrc` sets `ignore-workspace-root-check=true`. Keep it. `eve add` installs packages with a plain `pnpm add`, and because this folder has a `pnpm-workspace.yaml`, pnpm otherwise refuses with `ERR_PNPM_ADDING_TO_ROOT`. eve hides that and only prints "Dependency installation failed".

For the Web Chat installer, these answers keep everything local:

```bash
pnpm exec eve add channel/web --non-interactive \
  --answer 'web-framework="next"' \
  --answer 'web-hosting="next"' \
  --answer 'web-authentication="custom"'
```

The eve docs ship in `node_modules/eve/docs/`.
