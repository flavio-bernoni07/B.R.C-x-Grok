# agent-core: guide for coding agents

The final app: **Risolve**, Riso Scotti's back office. It is one Next.js 16 app that also hosts the [eve](https://github.com/vercel/eve) agent (eve `1.0.0-rc.3`, Grok through `@ai-sdk/xai`). Everything runs locally: no Vercel account, no Docker, no database server. State lives in one SQLite file (Drizzle + better-sqlite3).

The Order, Shipping, Dispute, threeway and benchmark code is a one-to-one TypeScript port of the Python rows in the repo root, which stay as the reference. Read `PORTING.md` for the contract every row follows, and `../DECISIONS.md` for the rules.

## Before you write code

- **eve:** read `node_modules/eve/docs/` (start at `README.md`). Don't rely on memory.
- **Next.js 16:** read `node_modules/next/dist/docs/` before touching `apps/web/` (breaking changes; see `apps/web/AGENTS.md`).
- **Design:** the HeyHandy UI kit (`../../HeyHandy/brand/UI.md`, `tokens.ts` `ui`) is ported to `apps/web/components/kit/`. Use only the kit and the brand tokens in `apps/web/app/globals.css` (`text-ink`, `text-ink-68`, `bg-hh-seasalt`, `bg-hh-honeydew`, `bg-st-attention`…). Use Satoshi, sentence case, no new colours.

## Environment

- Node 24 (`nvm use` reads `.nvmrc`) and pnpm only. `.env.local` holds `XAI_API_KEY`; never print or commit it.
- **Keep `.npmrc`** (`ignore-workspace-root-check=true`). Without it, `eve add …` fails with a vague "Dependency installation failed".
- `better-sqlite3` is native. If there is no prebuilt binary for your Node, install `node-gyp` (`npm i -g node-gyp`) and run `pnpm rebuild better-sqlite3`. It is listed in `agent.ts` `build.externalDependencies`; without that, the agent's tools can't load it inside eve's snapshot.
- Python forecaster: `pnpm setup:py` once (uv).

## Principles

1. **One feature, three faces.** Write it once in `agent/lib/<area>/`, then expose it as a tool (`agent/tools/<area>_<verb>.ts`), an API route (`apps/web/app/api/<area>/…`) and a component. The page and the chat card are the same component, so what Grok shows looks like the app.
2. **One thread.** The Overview is the agent's chat. Its first message is the state of things (`components/core/overview.tsx`), and answers continue below. Other pages link to it with "Ask Grok" (`askHref(question)`).
3. **People decide.** No tool approves a sign-off or decides a case. The person decides in `SignoffCard`, which posts to `/api/signoffs/[caseId]/decide`. That route calls the row's `decideSignoff` and, on an order confirmation, hands the order to Shipping.
4. **Code writes every document and amount.** Grok proposes JSON; code validates; there is no euro threshold.
5. **Faithful to the Python.** Statuses, IDs, audit actions, document kinds and messages match the Python rows. `tests/golden.test.ts` checks the end-to-end run. When you change behaviour, change it in both, or note it in `../DECISIONS.md`.
6. **Fast turns.** Main reasoning is `"low"`. Keep skills short with few tool calls. Large tool outputs use `toModelOutput` to give the model the gist while the card gets everything.

## Recipes

**Add a feature:** lib function → tool → route → component in `components/<area>/` → add it to that area's `cards` in `index.ts` (already merged by the registry) → mention the tool in `agent/instructions.md`.

**Add a page:** `apps/web/app/(app)/<name>/page.tsx` rendering a view that wraps itself in `Page` from `components/shell/app-shell`. Add it to `NAV` in `app-shell.tsx`, with an icon in `components/kit/icons.tsx` drawn in the same line weight.

**Reset the data:** `pnpm db:reset` (or `--empty` for the world only). Set `BRC_SEED=none` to open an empty database without the golden demo.

## Testing

```bash
pnpm test                                         # all Vitest suites
pnpm typecheck                                    # agent code
pnpm exec tsc --noEmit -p apps/web/tsconfig.json  # web app
pnpm dev:web                                      # server on port 3000, then the Mac app
```

To test a real turn over HTTP while `dev:web` runs: `POST /eve/v1/session {"message": …}`, then read `GET /eve/v1/session/<id>/stream` (NDJSON, `facts[].type`: `call.requested`, `call.settled`, `content.completed`, `turn.settled`). `GET /eve/v1/info` lists the tools and skills. Stop any dev server you start.

## Don't

- Don't use an AI Gateway model string; keep `xai.responses(...)`.
- Don't add Docker or a database server.
- Don't edit `data/disputes/playbook.md` from the app. It uses `data/runtime/playbook.md`.
- Don't edit `node_modules`.
